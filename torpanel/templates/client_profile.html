پروفایل بهینه Xray

تبدیل کانفیگ VLESS + REALITY TCP به JSON با DNS-over-HTTPS و جلوگیری از نشت UDP

بازگشت
این فایل برای کلاینت‌های سازگار با Xray است، نه برای جایگزینی تنظیمات اصلی سرور 3x-ui. DNS با DoH از طریق همان اتصال VLESS عبور می‌کند؛ UDP غیر از درخواست‌های DNS داخلی مسدود می‌شود. برای جلوگیری از DNS leak کلاینت، Proxy برنامه‌ها را روی SOCKS5 با Remote DNS تنظیم کنید.
این تنظیمات محدودیت سرعت مدارهای Tor را از بین نمی‌برد. فقط مشکلات محتمل DNS/QUIC و مسیرهای مستقیم ناخواسته در JSON پیشین را حذف می‌کند. فایل خروجی حاوی UUID اشتراک شماست؛ آن را منتشر نکنید.
