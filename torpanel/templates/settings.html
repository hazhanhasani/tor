اتصال 3x-ui و روش دسترسی Tor به شبکه را از همین صفحه مدیریت کنید.

سازگاری Tor با شبکه‌های محدود / سرور ایران
سرور ایران: Installer برای دانلود Xray و بروزرسانی‌ها ابتدا مسیرهای رسمی GitHub را امتحان می‌کند و در صورت مشکل از GitHub API Asset fallback استفاده می‌کند. همچنین Proxy و Release Mirror سفارشی پشتیبانی می‌شوند. برای خود شبکه Tor در صورت مسدود بودن اتصال مستقیم، از obfs4 Bridge استفاده کنید.
راهنمای خطا: خطای 401 یعنی خود توکن توسط 3x-ui پذیرفته نشده است؛ خطای 403 یعنی توکن معتبر است ولی سطح دسترسی کافی ندارد؛ خطای 404 معمولاً به معنی URL یا base path اشتباه است.
نحوه Sync: فقط Inbound/Outbound/Ruleهایی که با Tag اختصاصی torloc- ساخته شده‌اند توسط پروژه مدیریت می‌شوند و تنظیمات دستی دیگر 3x-ui دست‌نخورده می‌مانند.
